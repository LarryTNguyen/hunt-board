# Shared UI components

The frontend is a framework-free static implementation. Visual component markup lives in
`mock-designs/index.html`, component styles live in `mock-designs/styles.css`, and the responsive menu
behavior lives in `mock-designs/script.js`.

## Implemented visual components

- `Wordmark`: inline survey-compass mark with Hunt Board naming and field-desk annotation.
- `SavannahHorizon`: original inline SVG acacia and grass artwork framing the route map.
- `SiteNav`: sticky navigation with a progressively enhanced mobile menu.
- `RouteMap`: accessible inline SVG showing ATS sources through the ingestion pipeline.
- `MethodStep`: three sequential process modules with compact structural diagrams.
- `FilmStrip`: responsive sample-posting frames with camera-film sprocket treatment.
- `DispatchPanel`: closing dark-forest statement with internal anchor actions.
